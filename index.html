1D Vertical Flight Dynamics & Atmospheric Drag Equations (Slides 19–22)

1. Time-Variant Rocket Mass Function
m(t) = m₀ - ṁ · t   (t ≤ t_burn)
m(t) = m₀ - ṁ · t_burn   (t > t_burn)

Initial mass m₀ = 96,950 kg, cluster propellant depletion rate ṁ = 256.5 kg/s, with total powered burn duration t_burn = 293.7 s.

2. Atmospheric Density Models (Barometric & Lapse Rate)
ρ(h) = ρ₀ · e^(-h / H)
ρ(h) = ρ₀ · [1 - (L·h) / T₀]^[(g·M)/(R·L) - 1]

Sea-level density ρ₀ = 1.225 kg/m³, scale height H = 8,500 m, lapse rate L = 0.0065 K/m, T₀ = 288.15 K, g = 9.80665 m/s².

3. Supersonic Aerodynamic Wave & Skin Friction Drag
D(t) = 0.5 · ρ(h) · v(t)² · C_D · A

Drag coefficient optimized using Power-Law nose cone (n=0.66/0.75, C_D = 0.254–0.300) and symmetric NACA 0006 stabilizing fins (C_D = 0.0055).

4. 1D Net Acceleration & State ODE Integration
a(t) = [T_active - D(t)] / m(t) - g(h)
v_{n+1} = v_n + a_n · Δt,   h_{n+1} = h_n + v_n · Δt

Discrete state Euler / ODE45 integration advancing velocity and altitude through atmospheric ascent to burnout and apogee.
